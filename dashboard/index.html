How to interact

  • Push a CloudWatch alarm for the demo instance past 80% CPU (for example, run a CPU load on it). A case appears here within a minute.
  • The agent investigates through the READ gateway and emails the operator a diagnosis and proposed plan.
  • Reply by email: DETAILS for more evidence, a free-text question to follow up, APPROVE PLAN-... <token> to run the plan, REJECT to decline, or ESCALATE to hand over to a human.
  • Every approved action is re-checked before it runs and verified afterwards. This page updates every 15 seconds.
Read-only. Emails are masked and secrets are never stored or shown.
